# Text outputs

## What is brief (negate)

- Topic, industry, product names, people, companies.
- The story's facts: what happened, numbers, dates, money.
- The specific takeaway and lesson content.
- One-off phrases that appear in a single output.

## What is form (measure)

| Axis | Look for |
|---|---|
| Skeleton | Line and block order, blank lines, block count, which blocks are optional |
| Fixed strings | Lines or openers identical in every output (`profile` lists them) |
| Openers | First token per line (`line shapes`): "Last", "1/", "What's", "P.S." |
| Hook | Type (contrarian claim, question, stat), sentence count, length range |
| Sections | The role of each block: story, lessons, proof, CTA, sign-off |
| Voice | Person (I, you, we), tense, sentence length, reading level, tone |
| Mechanics | Emojis, hashtags, markdown, dashes, contractions, number style, punctuation |
| Conditionals | A block present in some outputs: find the brief property that predicts it |
| Length | Word and line ranges (class: range) |

## Conditional rules

When a feature appears in k of N outputs, sort the outputs into with and
without. Compare their briefs. If one brief property splits them cleanly
(failure vs success, list vs story, product vs opinion), write an if/then rule
and cite the outputs. If no property splits them, it is a tendency.

## Diffing a replay against its original

Go block by block. For each block note: present in both, same role, same
opener, length close, same mechanics. Ignore content differences; the brief
was inferred, so wording will differ. A difference matters only if it is about
form.
